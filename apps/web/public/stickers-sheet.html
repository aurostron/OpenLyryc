Creative Brief & Notes for the Illustrator / Redraw Artist

  • Style: Hand-drawn, loose, organic doodle stickers (like sketches inside a musician's lyric notebook).
  • Linework: Uniform 2.5px to 3.5px stroke width with rounded ends (stroke-linecap: round).
  • Grid: Each sticker is constructed within a viewBox="0 0 64 64" bounding box so it scales cleanly to any resolution.
  • Colors: Designed for dark mode (`#08080a`), each with an accent tint (amber, emerald, rose, indigo, cyan, violet, orange, blue, pink, yellow, teal, gold).
