# Security

## Reporting a problem

Do not open a public issue for a security bug.

Email `security@openlyryc.dev` with:

- What you found
- Steps to reproduce it
- Which browser and version you used
- What an attacker could do with it

You should get a reply within a few days. Please give us time to fix it before you post about it.

## Please do not

- Test against another person's account
- Run scans or load tests against the hosted service
- Upload other people's private data
- Open a PR that adds a real token, password, or database key

## Scope

This covers the code in this repository and the hosted app at `openlyryc.pages.dev`. Unison Hub's server code is not in this repo.
